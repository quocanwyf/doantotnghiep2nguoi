# Giai đoạn 05 — đánh giá

Ghi `comparison.md` khi có số liệu: baseline, proposed, chênh lệch, độ biến thiên giữa các run, điều kiện đo và giới hạn kết luận. Nếu có nhiều cải tiến, bổ sung ablation để tách tác động.

Mỗi run có một file theo [RUN-TEMPLATE.md](RUN-TEMPLATE.md). Không kết luận “tốt hơn” khi metric, split hoặc điều kiện đo khác nhau mà chưa giải thích.
