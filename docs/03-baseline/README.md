# Giai đoạn 03 — baseline

Ghi giao thức của T-010 tại `T-010-protocol.md` khi bắt đầu: nguồn và phiên bản dữ liệu, split, preprocessing, model, cấu hình, seed, metric, thiết bị và cách chạy lại. Mỗi run Markdown của T-011 mang tên `runs/T-011-<run-id>.md`, theo mẫu dùng chung ở `../05-evaluation/RUN-TEMPLATE.md`. Phân tích lỗi T-012 sẽ ghi tại `T-012-error-analysis.md`. Các file này chỉ tạo khi bắt đầu task tương ứng; `DECISION_LOGIC.md` của phase được cập nhật song song.

**Điều kiện chuyển giai đoạn:** baseline chạy lại được và có kết quả làm mốc so sánh với proposed.
