# Giai đoạn 03 — baseline

Đọc [T-010 — giao thức baseline đang được review](T-010-protocol.md) và [logic quyết định phase 03](DECISION_LOGIC.md). T-010 ghi nguồn/phiên bản dữ liệu, split, preprocessing, candidate/weight, cấu hình, seed, metric, thiết bị và cách chạy lại **trước khi T-011 xem kết quả**. Hiện protocol chưa freeze vì T-008/T-009 còn review và các gate dữ liệu/policy/tiêu chí chấp nhận chưa hoàn tất. Mỗi run có hồ sơ riêng trong `runs/` theo cùng mẫu ở `../05-evaluation/RUN-TEMPLATE.md`.

**Điều kiện chuyển giai đoạn:** baseline chạy lại được và có kết quả làm mốc so sánh với proposed.
