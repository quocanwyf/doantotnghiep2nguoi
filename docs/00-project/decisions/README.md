# Quyết định chính thức

Mỗi quyết định quan trọng có một file `D-001-ten-ngan.md`; không sửa mất lịch sử. Quyết định mới thay thế mục cũ bằng liên kết hai chiều. Hiện chưa có quyết định kỹ thuật/nghiệp vụ nào được xác nhận từ tài liệu định hướng.

Mẫu:

```md
# D-001 — Tên quyết định

- Trạng thái: Đề xuất | Nhóm đã chốt | Thầy đã xác nhận | Đã thay thế
- Ngày:
- Người chốt/xác nhận:
- Vấn đề và các phương án:
- Lựa chọn và lý do:
- Bằng chứng: biên bản, khảo sát hoặc thí nghiệm
- Tác động/giới hạn:
- Thay thế quyết định nào (nếu có):
```
