# Quyết định chính thức

Mỗi quyết định quan trọng có một file `D-001-ten-ngan.md`; không sửa mất lịch sử. Quyết định mới thay thế mục cũ bằng liên kết hai chiều. Đã ghi [D-001 — chọn bài toán cửa phòng thi](D-001-chon-bai-toan-cua-phong-thi.md) và [D-002 — dùng T-005 làm hướng khảo sát](D-002-chon-huong-khao-sat-t005.md) theo xác nhận của Quốc An về lựa chọn nhóm. D-002 là survey decision, chưa phải quyết định kỹ thuật cuối; chưa ghi nhận thầy xác nhận hai quyết định này.

```md

- Vấn đề và các phương án:
- Lựa chọn và lý do:

- Tác động/giới hạn:
- Thay thế quyết định nào (nếu có):
```
